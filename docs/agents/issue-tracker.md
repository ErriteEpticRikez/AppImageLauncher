# Issue tracker

Use GitHub Issues in ErriteEpticRikez/AppImageLauncher via the authenticated gh CLI. Specs and implementation tickets use the ready-for-agent label. Tickets link to their parent spec and declare dependencies. The integration PR references all completed work with closing keywords; merging it into master closes the issues. Keep unresolved work open and the PR draft if implementation is incomplete. Do not merge without a user request.

Use --body-file for multiline issue/PR bodies. Link each PR to the T3 thread immediately after creation.
